# Priyanshu Tiwary — Rhymeforge Studios

A responsive portfolio built with React and Vite, with an editorial aesthetic inspired by the supplied reference. Its first pass uses CSS-based film-frame artwork instead of an unapproved portrait or client project.

## Run locally

Requires Node.js 18 or newer.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Use `npm run build` to create a production build and `npm run preview` to inspect it locally.

## Updating the portfolio

- Edit content in `src/site-markup.js`.
- Edit React composition and interactions in `src/App.jsx`.
- Edit styles in `src/styles.css`.
- Replace clearly marked work placeholders with approved project descriptions and cleared images or video posters.

The ambient aurora, viewport reveals, spotlight cards, and magnetic links adapt interaction patterns from [React Bits](https://reactbits.dev/). React Bits publishes components as source to copy into a project, rather than as a normal runtime dependency; these effects are lightweight local implementations tuned to this design. Google Fonts load when available, with Georgia and Arial as fallbacks. Contact links are placeholders until approved public contact details are added.
